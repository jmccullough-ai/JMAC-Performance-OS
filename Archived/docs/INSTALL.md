# JMAC OS Install Checklist

## First Install
1. Copy all files in `/apps-script` into matching Apps Script files.
2. Save the Apps Script project.
3. Run `JMAC_install()`.
4. Authorize permissions.
5. Return to the Google Sheet and refresh the browser.
6. Use `JMAC OS → Compose Program`.

## Future Releases
Only replace the modules listed in each release changelog.

## Notes
The Google Sheet is the UI. Apps Script is the runtime. Database sheets are hidden but editable by the coach/admin.
