ATHENA Production — Milestone 1 Build Notes

Milestone:
1 — Core Foundation

Purpose:
Create the permanent ATHENA Production foundation with clean standalone Apps Script modules.

What this build does:
- Creates required foundation sheets
- Seeds lookup values
- Seeds sport profiles
- Adds Hockey and Golf to the sport database foundation
- Creates empty EXERCISE_MASTER structure
- Creates PROGRAM_RULES structure
- Creates HOME dropdowns
- Creates a HEALTH_CHECK validator
- Creates one ATHENA Production menu using the only allowed onOpen()

What this build does not do yet:
- It does not generate workouts
- It does not select exercises
- It does not create the final print format
- It does not use ATHENA v2 or ATHENA v3 code
- It does not depend on any previous build

Architecture decision:
Milestone 1 is intentionally small. The goal is to make the foundation compile cleanly before adding the exercise database, scoring, decision engine, workout generator, or print system.

Production rules satisfied:
- GitHub remains master
- Every Apps Script module is a separate .txt file
- No Rescue/Patch/Hotfix/Compatibility naming
- Only one onOpen()
- No duplicate functions inside this milestone
- Build compiles without prototype dependencies
